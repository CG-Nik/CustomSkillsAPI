# CustomSkillsAPI  
This mod serves as an API mod to allow other mods to add custom skills.  
This mod needs to be on both the Client and the Server in order for custom skills to work properly, the same goes for any mods using this mod as a dependency.  

As of now, this mod just has a few hooks to ensure that custom skills from multiple different mods load properly.  
In the future, this mod will have actual API features.  

This is an unofficial, fan-made mod for A Township Tale. This mod is not affiliated with or endorsed by the owners or developers of A Township Tale.
